Cómo sacar la clave (5 minutos)
  1. Entra en console.cloud.google.com y crea un proyecto (por ejemplo, «Canalitos»).
  2. En «APIs y servicios → Biblioteca», busca YouTube Data API v3 y dale a «Habilitar».
  3. En «Credenciales → Crear credenciales → Clave de API», copia la clave.
  4. Edita la clave: en «Restricciones de aplicaciones» elige «Sitios web» y añade . En «Restricciones de API», deja solo YouTube Data API v3.
  5. Pégala arriba y dale a «Guardar y comprobar».

Si olvidas el PIN, borra los datos de esta web en los ajustes del navegador y vuelve a configurarla.
